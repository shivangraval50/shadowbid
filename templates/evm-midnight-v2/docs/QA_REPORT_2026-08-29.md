## Privacy review evidence

Static review was used only because no owned API, database, browser, or logs
were available at runtime.

- `ShadowBidAuction` emits `CommitmentRecorded(auctionId, commitment)`; it does
  not emit a bidder, opening, salt, or bid amount for a commitment. The public
  settlement event intentionally emits the winner and winning amount.
- The Compact primitive forwards only `auctionId` and `commitment`.
- `ingestShadowBidFact` rejects Midnight payloads that contain `amount` or
  `salt` before persistence.
- `001-shadowbid.sql` contains no private-opening or losing-amount columns;
  public API routes expose public auction state and commitment hashes only.
- The reducer test passed its ordering/replay/terminal-state checks. The batcher
  test passed its fail-closed coordinator, malformed input, forged result,
  premature-state, and replay cases.

This is static evidence of no intended losing-bid disclosure in source. It is
not a substitute for the blocked runtime API/DB/log/browser privacy test.
